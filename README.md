# 🌐 Personal Portfolio Website

This is my **personal portfolio website**, built with HTML, CSS, and JavaScript. It highlights my background, showcases my projects, lists my skills, and provides ways to get in touch with me. The site is designed to reflect both creativity and professionalism.

## 📌 Features

- ✅ Clean and modern design
- ✅ Responsive layout for all devices
- ✅ About Me section
- ✅ Projects showcase with descriptions and links
- ✅ Skills & technologies section
- ✅ Contact information

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **Deployment**: AWS S3
